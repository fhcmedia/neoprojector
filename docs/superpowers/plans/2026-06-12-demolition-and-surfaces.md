# Demolition + Surfaces Implementation Plan (sub-project 1 of 3)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove the presenter view, presentation editor, settings page, and template/overlay editor routes; re-home settings and both editors as inline surfaces on the Show page driven by a `surface` search param.

**Architecture:** The `/` route gains typed search params (`surface`, `editId`). The Show page swaps pane contents by surface: settings replaces the center pane; editors replace the center pane (canvas) AND the schedule pane (options/inspector), with displays preview + library staying visible. Editors follow a Provider + Options + Canvas split because TanStack Router has a single Outlet — search params bridge the two regions.

**Tech Stack:** React 19, TanStack Router (file-based, vite plugin codegen), TanStack Query, Wails3 bindings, Tailwind. No test harness exists yet; verification is typecheck + build + scripted dev checks.

**Spec:** `docs/superpowers/specs/2026-06-12-minimal-core-design.md`

- **NEVER run `git commit`.** The user reviews and commits at each checkpoint. Stop at every `CHECKPOINT` block and report.
- `routeTree.gen.ts` is generated by the vite plugin. After ANY route file is created/deleted, regenerate BEFORE typechecking:
  `pnpm exec vite build --logLevel error` (regenerates the tree, catches broken imports), then `rm -f tsconfig.tsbuildinfo && pnpm exec tsc -b` (types).
  This combined sequence is called **VERIFY** below.
- Style: flat & squared (`rounded-none`), match surrounding idiom.

// Surfaces are inline views that take over Show-page panes instead of
// being routes — the app's one window stays the Show page and content
// overlays it. Driven by typed search params on "/" so the shell

export const SURFACES = ["settings", "template", "overlay"] as const
export type Surface = (typeof SURFACES)[number]

export function parseSurface(v: unknown): Surface | undefined {

### Task 2.2: Esc-to-close hook

**Files:**
- Create: `features/surfaces/use-surface-esc.ts`

- [ ] **Step 1: Create the hook**

```ts
import { useEffect } from "react"

// Capture-phase Esc handler: surfaces must close on Esc BEFORE the
// global clear-live keybind sees the event (use-keybinds listens at
// bubble phase on window). `when` gates installation so the hook is
// declared unconditionally by the page. onEsc returning false lets an
// editor implement deselect-then-exit: false = handled internally,
// keep the surface open.
export function useSurfaceEsc(when: boolean, onEsc: () => boolean | void) {
  useEffect(() => {
    if (!when) return
    function onKey(e: KeyboardEvent) {
      if (e.key !== "Escape") return
      // Don't steal Esc from open dialogs/popovers or text inputs.
      const t = e.target as HTMLElement | null
      if (t && (t.closest("[role=dialog]") || t.tagName === "INPUT" || t.tagName === "TEXTAREA")) return
      const handled = onEsc()
      if (handled === false) {
        // editor consumed it internally (e.g. deselect) — still stop
        // the clear-live keybind from also firing.
      }
      e.preventDefault()
      e.stopImmediatePropagation()
    }
    window.addEventListener("keydown", onKey, { capture: true })
    return () => window.removeEventListener("keydown", onKey, { capture: true })
  }, [when, onEsc])
}
```
